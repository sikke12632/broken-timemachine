# 고장 난 타임머신

5학년 교실에서 2~4명이 한 팀이 되어 각자 기기로 들어와, 서로 다른 화면을 보며 **말로 설명해서** 고장 난 타임머신을 고치는 협동 방탈출 게임입니다.

* 게임: https://sikke12632.github.io/broken-timemachine/
* 6단계 + 마지막 「시간의 문」(팀 모두의 단서가 있어야 열림)
* 장치 10개 + 마지막 문: 전선 상자(조건 규칙), 별자리 자물쇠(선대칭·점대칭), 전개도 상자(정육면체 전개도), 시대 다이얼(고조선~조선 문화유산), 어림 자물쇠(올림·버림·반올림), 깜빡이 단추(바꿈 규칙), 배관 미로(좌표·방향), 가능성 주머니(평균과 가능성), 그림자 맞추기(합동), 연표 줄 세우기(우리 역사), 시간의 문(차례 바꾸기 규칙)
* 장치마다 그림 설명서(옵션에서 끄기)
* 바뀐 점: `패치노트.md`
* 그림·3D 모형은 모두 코드로 만들었습니다. 사용한 라이브러리·글꼴·역사 내용의 근거는 `CREDITS.md`.
